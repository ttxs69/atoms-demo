# 08 — 中断休息：额度耗尽不启动

**What to build:** 额度不够时，任务**根本不启动**——不是启动了再失败。
用户看到明确的提示和"什么时候恢复"，而不是花了时间等一个必然失败的过程。

同时处理几个输入侧的边界：空输入不算一次生成，超长输入明确拒绝。

额度计量的**实现**属于 `forge-accounts`。这张票只负责：
在状态机里正确进入 `blocked_credits`，并且不让 Alex 做任何事。
