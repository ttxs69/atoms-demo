# 06 — 中途停止不丢文件

**What to build:** 停止按钮真的能停，而且已经写好的文件不会消失。
用户喊停之后能选择"继续刚才的"或者"换个方向重来"。
额度只按实际消耗结算，没发生的消耗退还。

中断语义来自 ticket 09 的决策：已写文件全部保留，那条未完成的助手消息标记为 `interrupted`，
下一轮 prompt 里明确告知"上一轮在此处被中断"，让模型知道上次到哪了。

**Blocked by:** 03 — 生成可跑应用并预览
