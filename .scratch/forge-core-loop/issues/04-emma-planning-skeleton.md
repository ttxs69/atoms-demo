# 04 — Emma 先规划，文件树骨架填入

**What to build:** Mike 先把任务分派给 Emma，Emma 返回一份结构化的功能描述和文件清单，
然后文件树以灰色占位全部长出，再由 Alex 逐个填充。

首次生成时，用户看到的不再是"Alex 直接开写"，而是"先知道做几件事，再看着它们逐一完成"。
进度是真实信号：文件数是已知分母，每一行从"待生成"变成"正在写"再变成"完成"是真实状态。
