# 09 — 只读代码查看器

**What to build:** 用户能浏览生成出来的文件树，点开任意一个文件读它的内容，有语法高亮。
只读——这一票不做编辑。

对不懂代码的用户，这是"它真的写了东西"的证据；对懂代码的用户，这是判断质量的入口。
两类用户都需要它，但都不需要在这里改代码（改代码走对话）。

**Blocked by:** 03 — 生成可跑应用并预览

**Status:** done

- [ ] 文件树列出沙箱里的项目文件（排除 `node_modules` 等噪声目录）
- [ ] 点击文件名显示该文件内容
- [ ] 内容有语法高亮（至少覆盖 ts / tsx / css / json / html）
- [ ] 明确只读——没有编辑入口，不给用户"这里能改"的错觉
- [ ] 文件内容从沙箱读取，不是从对话历史里拼出来的
- [ ] 大文件不卡界面
