# Explore Creative Ideas

- Source: https://help.atoms.dev/en/articles/12255829-how-to-explore-your-creative-ideas-on-atoms
- Summary: Atoms enables users create and do experiments with a low barrier
- Updated: Jul 29, 2026

---

In our **App World**, you can explore more about others' ideas, dev strategies, and prompt skills. If you like a project from others, you can try [remixing](https://help.atoms.dev/en/articles/12129010-remix) it or checking its dev history.

A very impressive Spaceship Racing Game. You can try it directly in App World. Also, if you see a fantastic project on GitHub, you can simply share the link on GitHub and send it to Agents.

You can tell agents: "Can you download the code from (the link), and deploy it."

Remember the good old days of playing defense games with classmates? This is a simple demo of one. To make a good case like this one, you need some prompt skills.

When you are interacting with agents, prompt is decisive for a good outcome. You can give agents a detailed and well-structured prompt, including the tech stack, key features of your project, and the ideal UI design to your agents.

**[Bomberman Style Game Dev](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F1c1d1d234121dbcc-53aypd)**

Bomberman is a beloved childhood classic. Here’s how to create your own Dream Game on Atoms:

-   Clearly outline the game logic in your prompt.
    
-   Provide agents with reference images to guide creation.
    
-   Use **[Select to Chat/Edit](https://help.atoms.dev/en/articles/12129698-app-viewer)** to modify specific visual elements.
