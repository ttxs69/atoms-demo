# Deployment Options

- Summary: Guide on local project deployment, GitHub/GitLab integration, and HTML file previewing in Atoms
- Updated: Jul 29, 2026

---

Learn about the different deployment and preview options available for your projects in Atoms, including local deployment methods and HTML previewing.

## Local Project Deployment

**Yes.** You can deploy your Atoms projects locally on your own machine or private infrastructure using either of the following methods:

1. **Direct Code Download**: Download your project source code as a `.zip` archive directly from the Editor panel and run it in your local development environment.
2. **GitHub / GitLab Integration**: Provide your repository address and Personal Access Token to your AI Agent team to automatically commit and push the codebase to your GitHub or GitLab repository for local setup and CI/CD deployment.

---

## HTML File Deployment & Previewing

Static standalone HTML deployment is not currently supported as a one-click hosting option.

### How to Preview HTML Files in Atoms

To preview an HTML file within the Atoms interface:

1. Open the **Editor** panel on the right side of the workspace.
2. Select and open your `index.html` file in the code viewer.
3. Click the **Play / Preview** icon in the bottom-left corner of the editor to launch the interactive live preview.
