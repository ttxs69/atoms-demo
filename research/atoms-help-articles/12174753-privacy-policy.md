Persistent cookies can be removed by following your web browser help file directions. A session cookie is temporary and disappears after you close your browser.

You can reset your web browser to refuse all cookies or to indicate when a cookie is being sent. However, some features of Atoms may not function properly if the ability to accept cookies is disabled.

For purposes of this Section, “improve” refers solely to improving the functionality, reliability, security, or user experience of those integration features and does not include developing, training, fine-tuning, or improving any artificial intelligence or machine-learning model. Atoms’ use and transfer of information received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Atoms does not use Google Workspace API Data, or transfer such data to any third party for the purpose of developing, training, fine-tuning, or improving any artificial intelligence or machine-learning model, including any generalized, non-personalized, personalized, or user-specific model. This restriction applies to raw data and information derived from such data, including aggregated or anonymized information. Google Workspace API Data may be transmitted to or processed by cloud infrastructure providers, technical service providers, or model service providers only to the extent necessary to provide the user-requested features. Processing such data through a pre-existing model solely to generate an output requested by the user constitutes inference and does not constitute model training. Such processing does not authorize any provider to use the data for its own advertising, model training, or other independent or secondary purposes. Where an AI-enabled feature uses a self-hosted or offline model, Google Workspace API Data is processed within an isolated environment controlled by Atoms. Such data is not transmitted through an API to, or made accessible to, the relevant external model provider. Atoms personnel will not access or read Google Workspace API Data except where the user has affirmatively authorized access to specific data for support or troubleshooting, where access is necessary for security, abuse prevention, or compliance with applicable law, or where the data has been aggregated or de-identified and is used for internal operations in accordance with applicable requirements. We retain Google Workspace API Data only for as long as reasonably necessary to provide the relevant user-requested features or comply with applicable law. Any transfer in connection with a merger, acquisition, reorganization, or sale of assets will be subject to any prior user consent required by the Google API Services User Data Policy or applicable law. No general description of data use, sharing, advertising, service improvement, or third-party processing elsewhere in this Privacy Policy or our Terms of Service expands the permitted uses of Google Workspace API Data described in Sections 1.3.3 and 1.3.4.
